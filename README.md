# 马哥的羽毛球教学网站 🏸

一个基于 **HTML + CSS** 构建的静态多页面羽毛球教学展示网站。  
网站围绕羽毛球基础训练内容进行整理，包含首页课程入口、独立课程详情页、视频展示、训练重点、相关推荐等模块，适合作为前端静态网站练手项目，也可作为羽毛球教学内容展示站点。

## 在线预览

访问地址：  
[https://badminton-site-two.vercel.app/](https://badminton-site-two.vercel.app/)

---

## 项目简介

本项目以“羽毛球教学网站”为主题，构建了一个具有课程入口页和多课程详情页的静态网站。  
首页展示训练路线、教学分类和课程卡片，点击课程后可进入对应详情页，查看视频、课程简介、学习重点、训练建议、常见错误以及相关推荐课程。

---

## 功能特色

- 多页面静态网站结构
- 首页课程入口页
- 5 个独立课程详情页
- 视频播放与课程封面展示
- 训练路线展示模块
- 教学分类展示模块
- 上一课 / 下一课导航
- 相关推荐课程推荐
- 响应式布局，适配不同屏幕宽度
- 已部署到 Vercel，可在线访问

---

## 课程内容

当前网站共包含 5 节课程：

1. 正手发高远球教学
2. 后场高远球练习
3. 杀球与步伐衔接
4. 网前搓球与扑球
5. 步伐基础与回位训练

## 项目结构

```text
.
├─ index.html
├─ serve.html
├─ clear.html
├─ smash.html
├─ netshot.html
├─ footwork.html
├─ styles.css
├─ images/
└─ videos/
````

### 文件说明

* `index.html`：网站首页，展示训练路线、教学分类和课程入口
* `serve.html`：正手发高远球课程详情页
* `clear.html`：后场高远球课程详情页
* `smash.html`：杀球与步伐衔接课程详情页
* `netshot.html`：网前搓球与扑球课程详情页
* `footwork.html`：步伐基础与回位训练课程详情页
* `styles.css`：全站公共样式文件
* `images/`：课程封面与页面图片资源
* `videos/`：课程视频资源

## 使用方法

### 本地运行

将项目克隆到本地后，可直接打开 `index.html` 进行查看。

也可以使用本地服务器运行：

```bash
python -m http.server 5500
```

然后在浏览器中访问：

```text
http://127.0.0.1:5500
```
